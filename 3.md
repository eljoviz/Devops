## 3. Herramientas CI/CD
Las herramientas de Integración Continua (**CI**) y Distribución/Despliegue Continuo (**CD**) automatizan el flujo desde el commit del desarrollador hasta la producción:
- **GitHub Actions / GitLab CI:** Plataformas nativas de repositorios que ejecutan flujos de trabajo automatizados mediante archivos de configuración YAML.
- **Jenkins:** Servidor de automatización de código abierto altamente extensible mediante complementos para cualquier arquitectura.
- **Argo CD / Flux:** Herramientas de despliegue continuo orientadas al paradigma **GitOps** para la gestión declarativa de clústeres en Kubernetes.
- **Azure DevOps:** Suite completa de Microsoft para gestión de proyectos, repositorios y pipelines integrados.
